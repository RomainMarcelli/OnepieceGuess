# **One Piece DLE**

**One Piece DLE** est un jeu en ligne interactif basé sur l'univers de **One Piece**. Ce projet, développé avec **Node.js**, **HTML**, **CSS**, et **JavaScript**, intègre une **API personnalisée** contenant toutes les informations sur les personnages de One Piece.

---

## **Concept du Jeu**

L'objectif principal du jeu est de tester vos connaissances sur One Piece en devinant :  
1. **Le personnage :**  
   - Devinez un personnage de One Piece en fonction des **indices** fournis.  
   - Les indices peuvent inclure le genre, l'affliation, la prime...

2. **Le fruit du démon :**  
   - Devinez à quel personnage appartient un fruit du démon donné.  
   - Les indices peuvent inclure le type du fruit

Ce jeu allie réflexion et passion pour l'univers de One Piece, tout en proposant une expérience enrichissante et amusante pour les fans.

---

## **Technologies Utilisées**

- **Backend :** Node.js (serveur et API personnalisée).  
- **Frontend :** HTML, CSS, et JavaScript.  

---

## **Fonctionnalités Principales**

### **1. Devinez le Personnage**
- Un système d'indices progressifs pour aider les joueurs à identifier un personnage.
- Un compteur pour suivre le nombre d'essais nécessaires avant d'avoir un indice.

### **2. Devinez le Fruit du Démon**
- Associez un fruit du démon (écrit en Japonais) à son propriétaire

### **3. Interface Utilisateur**
- Une interface simple et intuitive, permettant une immersion totale dans l'univers de One Piece.
- Une mise en page responsive adaptée aux mobiles et aux écrans d'ordinateurs.

## **Installation**

### **Prérequis :**
- **Node.js** doit être installé sur votre machine.
- Un navigateur moderne pour exécuter l'application côté client.

### **Étapes d'installation :**
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/RomainMarcelli/OnepieceGuess.git
   ```
2. Accédez au répertoire :
   ```bash
   cd OnepieceGuess
   ```
3. Installez les dépendances nécessaires :
   ```bash
   npm install
   ```
4. Lancez le serveur local :
   ```bash
   npm start
   ```
5. Accédez au jeu dans votre navigateur :
   ```bash
   http://localhost:3000
   ```
